# Stylus Plus

把 `HyperOS for Pad` 焦点笔能力改造成更实用的输入增强模块。

## 项目亮点

- 飞鼠输入：激光键单击进入输入控制，双击退出。
- 番茄小说翻页适配：在 `com.dragon.read` 进程内，将 `KEYCODE_PAGE_UP/DOWN` 映射为 `KEYCODE_VOLUME_UP/DOWN`。
- 分作用域设计：飞鼠逻辑和 App 适配逻辑分离，稳定且易排障。

## 使用方法

1. 安装模块并在 LSPosed 中启用。
2. 勾选推荐作用域：
   - `android`（系统进程，飞鼠相关 Hook）
   - `com.dragon.read`（番茄小说进程，翻页映射）
3. 重启作用域进程或重启设备后测试。

## 日志定位经验

- 统一使用模块前缀：`[StylusPlus_xposed]`。
- 先看初始化日志，再看行为日志。
- 核心判断顺序：
  1. Hook 是否初始化成功。
  2. 事件是否被拦截。
  3. 事件是否被正确映射并下发。

## 维护与扩展（最简单路径）

想继续给模块加功能，建议按下面做：

1. Fork 或克隆仓库并创建功能分支。
2. 按职责改最少文件：
   - `app/src/main/java/com/ljlvink/Hook/HookMain.java`：进程入口分流。
   - `app/src/main/java/com/ljlvink/Hook/StylusPlus.java`：核心 Hook 逻辑。
   - `app/src/main/java/com/ljlvink/utils/logutil.java`：日志等级与开关。
   - `app/src/main/res/values/arrays.xml`：LSPosed 推荐作用域。
3. 每次只做一类改动（功能或日志或文档）。
4. 通过 Actions 打包并在真机验证。
5. 通过日志确认后再合并。
